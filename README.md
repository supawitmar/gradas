# เว็บไซต์งานบริการการศึกษา — บัณฑิตวิทยาลัย มหาวิทยาลัยมหิดล

ไฟล์เดียวจบ: `index.html` (รวม CSS, JavaScript, ไอคอน และโลโก้ไว้ในไฟล์แล้ว ไม่ต้องใช้ไฟล์แนบ)

---

## 1. ดูหน้าเว็บในเครื่อง

ดับเบิลคลิก `index.html` เปิดด้วยเบราว์เซอร์ได้เลย

ถ้าอยากเปิดแบบมีเซิร์ฟเวอร์ (เหมือนของจริง) ใช้คำสั่งนี้ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8000

```bash
python -m http.server 8000
```

---

## 2. เอาขึ้นเว็บ (เลือกวิธีใดวิธีหนึ่ง)

### วิธี A — Netlify Drop (เร็วที่สุด ไม่ต้องใช้ git)

1. เปิด https://app.netlify.com/drop
2. ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ไปวาง
3. ได้ลิงก์ทันที เช่น `https://xxxx.netlify.app`
4. แก้ไฟล์แล้วอยากอัปเดต: ลากวางใหม่ทับได้เลย (ถ้าสมัครบัญชีไว้ ลิงก์จะคงเดิม)

### วิธี B — GitHub Pages (เหมาะกับการแก้ต่อเนื่องระยะยาว)

สร้าง repository ใหม่บน GitHub (เช่นชื่อ `as-website`) แล้วรันในโฟลเดอร์นี้

```bash
git init
git add .
git commit -m "Academic Service Section website"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/as-website.git
git push -u origin main
```

จากนั้นที่หน้า repository: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**
ลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/as-website/`

อัปเดตครั้งต่อไป

```bash
git add . && git commit -m "update" && git push
```

### วิธี C — เซิร์ฟเวอร์ของคณะ/มหาวิทยาลัย

อัปโหลด `index.html` ขึ้น web root ผ่าน FTP/SFTP ได้เลย ไม่ต้องตั้งค่าอะไรเพิ่ม (ไม่ใช้ PHP, ไม่ใช้ฐานข้อมูล)

## 3. แก้เนื้อหาเองได้ตรงไหนบ้าง

เปิด `index.html` ด้วย VS Code หรือ Notepad แล้วค้นหาตามนี้

| อยากแก้ | ค้นหาคำว่า | หมายเหตุ |
|---|---|---|
| สีทั้งเว็บ | `:root{` | ตัวแปรสี navy / blue / gold |
| ไอคอน | `const ICONS` | ไอคอนเส้น SVG |
| ไทม์ไลน์ ป.เอก | `const PHD` | 7 ขั้นตอนตามเอกสารบัณฑิตวิทยาลัย |
| ไทม์ไลน์ ป.โท แผน ก / ข | `PATH.mscA` / `PATH.mscB` | |
| การ์ด Shortcuts และเนื้อหาแต่ละบทบาท | `const ROLES` | นักศึกษา / อาจารย์ / เจ้าหน้าที่ |
| ลิงก์การ์ด "ข้อกำหนดรูปเล่มอิเล็กทรอนิกส์" | `href:{th:` | แยกลิงก์ตามภาษา |
| ตารางแบบฟอร์ม | `const FORMS` | ใส่ลิงก์ดาวน์โหลดแทน `href="#"` |
| ประกาศ/ข้อบังคับ | `const RULES` | ใส่ชื่อและลิงก์จริงแทน `[ชื่อประกาศ]` |
| คำแปลภาษาอังกฤษ | `const EN` | key คือข้อความไทย ถ้าไม่มี key จะแสดงภาษาไทยเดิม |
| เบอร์โทร / LINE | `024414125` | |

**ข้อควรระวัง:** เวลาเพิ่มข้อความไทยใหม่ ให้เพิ่มคำแปลใน `const EN` ด้วย ไม่อย่างนั้นหน้า EN จะมีตัวอักษรไทยโผล่

## 4. ยังไม่ได้ใส่ข้อมูลจริง (ต้องแก้ก่อนเผยแพร่)

- ลิงก์ดาวน์โหลดแบบฟอร์มทุกอัน ยังเป็น `#`
- ชื่อและลิงก์ประกาศ/ข้อบังคับ ยังเป็น `[ชื่อประกาศ]` `[ชื่อข้อบังคับ]`
- ลิงก์คู่มือ/เทมเพลต และ Dashboard ยังเป็น `#`
- กำหนดการของเจ้าหน้าที่ ยังเป็น `[วันที่]`
- เนื้อหาส่วนอาจารย์และเจ้าหน้าที่ เป็นฉบับร่างที่ยังไม่ได้ตรวจกับเอกสารจริง
